## Hi there 👋

This is the GitHub organisation for the **FAST Dev Team** — a group of Computer Science students from **FAST NUCES Karachi**.

We collaborate on **university semester projects** across different courses, demonstrating our progression from fundamentals to databases, full-stack, and AI.

### Featured Projects

- **[Karachi Smart Transit System](https://github.com/FAST-Dev-Team-Semester-Projects/karachi-smart-transit-system)** — Full-stack transit management with simulated real-time bus tracking, 12-table 3NF database, triggers, and Socket.IO. *(Database Systems)*
- **[AI Firefighter Rescue System](https://github.com/FAST-Dev-Team-Semester-Projects/ai-firefighter-rescue-system)** — Pathfinding visualizer comparing A*, BFS, and DFS on weighted hazard grids. *(Artificial Intelligence Lab)*
- **[Scientific Calculator](https://github.com/FAST-Dev-Team-Semester-Projects/Scientific-Calculator-ASM)** — Assembly + C++ scientific calculator. *(Computer Organization & Assembly Language)*
- **[Pac-Man Game](https://github.com/FAST-Dev-Team-Semester-Projects/Pac-Man-Game)** — Classic arcade game in C. *(Programming Fundamentals)*
- **[Task Management System](https://github.com/FAST-Dev-Team-Semester-Projects/Task-Management-System)** — OOP-based task manager in C++. *(Object Oriented Programming)*
